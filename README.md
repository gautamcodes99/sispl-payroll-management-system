# 💼 SISPL Payroll Management System

An Enterprise Payroll Management System built using **NestJS**, **Prisma ORM**, **PostgreSQL**, and **React**.

## 🚀 Project Overview

This application helps organizations manage:

- Employee Records
- Payroll Processing
- Attendance
- Leave Management
- Salary Structure
- Payslip Generation
- User Authentication
- Role Based Access Control
- Reports & Analytics

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/gautamcodes99/sispl-payroll-management-system.git
```

### Backend

```bash
cd backend
npm install
```

### Configure Environment

Create a `.env` file.

```
DATABASE_URL=your_postgresql_connection_string
```

### Run Prisma Migration

```bash
npx prisma migrate dev
```

### Start Backend

```bash
npm run start:dev
```
